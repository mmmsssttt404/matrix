## 二、徐瑞（组员，`xuruiz`）— 40 条标注评估集、JEVDB 真机排错与 Prune-First 消融分析

### 1. 个人负责模块
我主要负责：（1）12 家公司 40 条人工标注语义查询评估集（`evaluation/documents.csv`、`labels.csv`、`evaluate.py`）；（2）WSL2 Linux 真机部署 `jevdb==0.1.0 + duckdb==1.4.3` 与 DeepSeek JSON Schema 协议适配代理层（`scripts/jev_llm_proxy.py`）；（3）PCA 载荷/风险贡献/闭式解对照诊断与项目总报告第 4–5 节主体撰写。

### 2. 我最关键的独立判断与重要修改
1. **打通真实 JEVDB 协议链路而非用 mock 敷衍**：实测 `jevdb==0.1.0` 时先后遭遇默认 Typesafe 后端地区限制（HTTP 451）与 DeepSeek 兼容端点不接受 `json_schema` 仅支持 `json_object`（HTTP 400）两大真实报错。我没有退回到纯关键词替代，而是专门编写了本地轻量协议适配层 `jev_llm_proxy.py`，将 JSON Schema 约束显式注入系统提示并做强校验重试（并补齐了本机 Bearer 鉴权、路径白名单与 4MB 请求体上限），最终完成 40/40 条真实语义查询、0 最终错误（总计 80,481 tokens）。
2. **基于真实误差诊断落地 `Prune-First` 消融**：分析 40 条查询结果后，我发现纯关键词 AND 精确率高但面对同义词/上位词（如 `technology mega-caps`、`graphics processors`）直接返回空集；而全量 JEVDB 虽然召回率高达 `0.969`，却有 14 条查询存在“沾边就选”的过度包含噪声，拉低了精确率（`0.826`）与精确匹配率（`0.600`）。顺着原论文《Prune First, Decide Fast》思想设计的两阶段 `Prune-First (K=3)` 粗排剪枝（词面命中 `<2` 篇时回退全量语义防漏检），不仅**剪枝掉 31.7%（328/480）的语义判定调用**，还把擦边噪声挡在粗排门外，使宏精确率反升至 **`0.854`**、精确匹配率升至 **`0.650`**，几乎无损保持宏 F1（`0.863`）。

### 3. 理解最深刻的部分
这次实验彻底打破了我“大模型一定比传统检索全面占优”的刻板印象：语义模型擅长高召回和跨表述理解，但天然倾向过度包含；传统 BM25 速度快、词面约束严，但缺乏语义泛化。二者通过“粗排剪枝 + 语义精判 + 低命中回退”级联结合，才是真实数据库系统兼顾成本与精度的正道。

### 2. 我最关键的独立判断与重要修改
1. **经双反例二次修正 `Lec9` 第 28 页半正定表述**：在核查 `Lec9` p.28 *"When A has zero eigenvalues, there is no LU factorzation"* 时，我先构造 $\mathrm{diag}(0,-1)$ 说明“顺序主子式非负 $\nRightarrow$ 半正定”，随后在多 Agent 数学交叉审计中进一步借助 $\mathrm{diag}(1,0)$ 与 Horn & Johnson Corollary 7.2.9 厘清了更深一层的事实：**在精确算术下，奇异对称半正定阵仍存在无行交换的 $LDL^T/R^TR$ 分解**（零主元强制剩余行列清零），真正失效的是严格正对角唯一性与浮点舍入稳定性，故工程上必须采用完全对称主元分解 $PAP^T=LDL^T$。同时我构造了全整数 $3\times 3$ 正定阵 $A=\begin{pmatrix}4&2&-2\\2&10&2\\-2&2&6\end{pmatrix}$，让读者一眼看清 $d_k=\Delta_k/\Delta_{k-1}$ 与 Cholesky 因子 $R$ 的关系。
2. **用真实 12 股数据实证 $\kappa_2(\Sigma)=\kappa_2(X)^2$ 与 Eckart–Young 定理**：对题目二 `data/prices.csv` 中 12 只美股去均值日收益率矩阵 $X\in\mathbb{R}^{252\times 12}$ 做 SVD 实测，精确验证了数据矩阵条件数 $\kappa_2(X)=6.9497$ 形成 Gram 协方差阵后直接平方恶化为 $\kappa_2(\Sigma)=48.2986$，且截断秩 $k=3$ 即捕获 `70.69%` 总能量、2-范数误差严格等于 $\sigma_4=0.250927$，绘制图 6.1 并统一阐释了 `Lec0` 中的图像压缩与 DeepSeek-V3 MLA / LoRA 低秩机制。
3. **坚持全量机器验算**：编写 `verify_manuscript_math.py` 自动验证全部 9 组定理/反例、真实数据 SVD 与全部 10 道课后题（5 题精确数值校验 + 5 题随机矩阵性质验证），杜绝任何手算笔误。

### 3. 理解最深刻的部分
从 2-范数 Eckart–Young–Mirsky 定理出发，仅凭一次“对 $B+(A-B)_{i-1}$ 秩上界为 $k+i-1$”的巧妙构造就能直接推出逐个奇异值不等式 $\sigma_i(A-B)\ge\sigma_{k+i}(A)$，进而平方求和自洽证出 Frobenius 范数最优性——这种不依赖复杂工具的构造证明极其优美，也把矩阵秩、奇异值谱与低秩压缩的本质彻底串成了一条线。
