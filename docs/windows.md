# Matrix Workbench · Windows桌面版

## 启动

解压整个文件夹，双击`MatrixWorkbench.exe`，或`start-windows.cmd`。请保留旁边的`_internal`目录，运行时无需自行安装Python。构建包为Windows x64版本，当前采用Qt Widgets与原生图表。

首次启动没有行情时，点击“下载课程研究数据”，或“文件→打开工作区”选择含`prices.csv`的目录。程序不生成展示行情。默认工作区位于Windows的本地应用数据目录下：`MatrixLab/MatrixWorkbench/workspace`，实际位置可通过打开工作区对话框查看。

## 使用

- 左侧自选股：点击切换股票，搜索过滤代码或公司名。
- 中部图表：日K线、MA20、成交量；滚轮缩放、拖动平移、十字光标查看单日OHLC。1M/3M/6M/1Y切换显示范围。
- 顶部研究日期：控制可见行情与研究截止时间；“最新”回到当前数据快照末日。
- 公司研究：关键词模式可离线使用，双击结果查看原文与来源；选中的公司可带入矩阵组合。
- 矩阵组合：选择股票、回看长度和收缩参数，计算协方差、权重与样本外对比。研究日期应早于最后一个交易日，才有后续行情供比较。
- 右侧模拟账户：先创建账户并选择一个历史起点；买卖与组合调仓按下一交易日开盘撮合。底部查看持仓、成交、权益与数据来源。

菜单快捷键：`Ctrl+O`打开工作区，`Ctrl+1/2/3`切换功能页，`Ctrl+E`导出成交，`Ctrl+Q`退出。中间分隔线可拖动调整面板宽高。

## JEVDB语义服务

JEVDB官方0.1.0预编译扩展目前面向Linux x86-64。Windows端保留本地行情、关键词研究、矩阵计算和模拟交易；真实语义查询通过Linux服务运行JEVDB。凭证未配置时会明确提示，不会将关键词匹配伪装为语义结果。

在Linux项目目录配置模型密钥与`MATRIX_JEVDB_SERVICE_TOKEN`后启动：

```bash
.venv/bin/python -m matrixlab.service --host 127.0.0.1 --port 8766
```

Windows可使用SSH端口转发：

```powershell
ssh -L 8766:127.0.0.1:8766 Linux用户名@Linux地址
```

在软件“连接设置”填写`http://127.0.0.1:8766`及相同的访问令牌，然后在公司研究中选择JEVDB语义模式。也可配置使用HTTPS的远程服务地址。研究服务仅处理资料筛选，交易账本始终保存在Windows本机。

## 数据与限制

软件使用真实历史数据快照，行情不是实时推送。价格采用总回报复权口径，订单单位为整数模拟份额。手续费、滑点和时钟规则见帮助菜单。`build-check.json`记录构建时的可执行文件测试，测试数据不包含在发行文件夹中。

这是未签名的课程软件构建包，没有申请Windows代码签名证书；不要求关闭系统防护。Qt库采用动态分发，许可和来源保留在第三方通知与`_internal/licenses/`目录。
