### 老师高频追问与参考回答
- **Q：为什么不在 Agent 批准时重新调用一次 LLM 而是执行预览单？**  
  A：因为大模型输出存在随机性，若批准时二次调用可能导致最终成交标的与人类刚审阅的提案不一致；按预览生成的确定性票据执行并绑定 `request_id` 幂等号，才能实现真正的“所见即所得”人工控制。

## 02. 徐瑞 — 40 条标注集设计、JEVDB 真机排错与 Prune-First 消融误差分析

### 演示分镜与操作路径（约 3 分钟）
1. **0:00–0:50 JEVDB 真机加载与协议适配排错**（展示 `JEVDB本机验证记录.pdf` 与 `scripts/jev_llm_proxy.py`）
   - 讲稿要点：“我负责 JEVDB 真机验证与评估体系。在 WSL2 Ubuntu 24.04 加载 `jevdb==0.1.0 + duckdb==1.4.3` 时遇到两个真实工程障碍：第一，默认 Typesafe 后端因地区限制返回 HTTP 451；第二，切到 DeepSeek 兼容端点后，JEVDB 固定发送 `json_schema` 而 DeepSeek 仅支持 `json_object` 返回 HTTP 400。为此我编写了本地协议适配层 `jev_llm_proxy.py`，把 schema 注入提示词并做强校验重试，最终 40 条真实查询实现 40/40 成功、0 最终错误。”
2. **0:50–2:05 40 条人工标注集与 Prune-First 消融核心发现**（展示 `项目总报告.pdf` 第 5 节表与 `evaluation/results/prune-ablation.json`）
   - 讲稿要点：“对比全语料库 IDF 修复后的关键词 AND+BM25（宏 F1 `0.792`）与全量 JEVDB（宏 F1 `0.865`），我们发现纯关键词在同义词查询（如 `technology mega-caps`）上直接返回空集，而全量 JEVDB 虽然召回率高达 `0.969`，却有 14 条查询存在‘相关就选’的过度包含噪声。按照论文《Prune First, Decide Fast》思路，我们做了两阶段 `Prune-First (K=3)` 消融：先用高速 BM25-OR 粗排截断无关文档（命中 `<2` 篇时回退全量语义以防漏检），结果不仅**剪枝掉 31.7%（328/480）语义调用**，还把噪声挡在了粗排门外，让宏精确率从 `0.826` **反升至 `0.854`**、精确匹配率从 `0.600` 升至 **`0.650`**！”
3. **2:05–2:50 误差分析与诚实边界声明**
   - 说明评估集规模（12 公司、40 查询）及 `prune_ablation` 为基于真实 DeepSeek 逐条判定的离线确定性重放（不伪造新调用），并说明 `deepseek-flash` 为当次端点配置标识。

### 老师高频追问与参考回答
- **Q：为什么 `Prune-First` 在减少 LLM 调用的同时精确率反而上升了？**  
  A：大模型语义判断倾向高召回、容易对擦边公司过度包含（14/40 条存在冗余命中）；第一阶段 BM25 粗排过滤掉了缺乏直接文本锚点的擦边文档，同时回退机制保住了同义词查询的召回，从而实现降本增精。

2. **0:55–2:15 关键定理证明补全与几何直觉**（展示 `第八章_特征值特征向量与正定矩阵_修订稿.pdf` 第 2–7 页）
   - 快速讲解 3 处自己理解最深的补充：（1）利用 `Lec6` Householder 酉基扩充补全 **Schur 酉三角化归纳证明**，并说明 $\kappa_2(U)=1$ 相比一般相似变换 $P^{-1}AP$ 的无条件数值稳定性；（2）用 Schur 定理两步极简证明 **正规矩阵酉对角化**（顺带直接证出 `Lec9` 习题 9）；（3）从 Courant–Fischer 一步推出 **Weyl 扰动界 $|\beta_i-\lambda_i|\le\|E\|_2$**，解释为何实对称阵特征值天然良态而亏损 Jordan 块扰动可达 $\varepsilon^{1/n}$。
3. **2:15–2:55 现代应用衔接（PageRank 幂迭代收敛率）**
   - 展示 §8.1.3 新增的 4 节点 Google 矩阵实算：阻尼系数 $d=0.85$ 将次主特征值压在 $|\lambda_2|=0.6010<0.85$，幂迭代 20 步误差即降至 `1.2e-5`，直接呼应 `Lec0 p.15`。

### 老师高频追问与参考回答
- **Q：为什么现代特征值求解器（LAPACK）不先展开特征多项式再求根？**  
  A：一方面受 Abel–Ruffini 定理限制 $n\ge 5$ 无根式解；更致命的是数值病态——Wilkinson 多项式系数微扰 $2^{-23}$ 就会令实根剧烈分裂为复根，因此工程上先用 Householder 约化为上 Hessenberg 阵，再走保正交的 Francis 隐式 QR 迭代。

## 04. 吴昀泽 — 正定/半正定辨析、第五/六章 SVD 联动与 Python 机器自动验算

### 演示分镜与操作路径（约 3 分钟）
1. **0:00–1:00 纠正 `Lec9` 第 28 页半正定两大误区与 Cholesky 整数例**（展示 `第八章修订稿.pdf` 第 8–9 页）
   - 讲稿要点：“我负责第八章 §8.4–8.5、第五/六章 SVD 联动专题和全套自动验算脚本。在核查 `Lec9` p.28 时，我通过双反例厘清了两个易错点：第一，`diag(0,-1)` 所有顺序主子式非负却不是半正定，必须检完 $2^n-1$ 个全主子式；第二，原课件断言奇异半正定阵不存在 LU 分解不够精确——其实在精确算术下，半正定阵一旦出现零主元 $s_{kk}=0$，由 $|s_{kj}|^2\le s_{kk}s_{jj}$ 会强制对应行列清零，因此精确 $LDL^T/R^TR$ 仍存在（如 `diag(1,0)`），真正失效的是严格正对角唯一性以及浮点舍入下的数值稳定性，故工程上必须做完全对称主元选择 $PAP^T=LDL^T$。同时我构造了一个全整数 $3\times 3$ 正定阵展示 $d_k=\Delta_k/\Delta_{k-1}$ 与 Cholesky 因子 $R$ 的对应，并补全了 Sylvester 惯性定律证明。”
2. **1:00–2:10 双题联动：真实 12 股协方差收缩与收益率 SVD 实测**（展示图 8.2、图 8.3 与 `第五六章联动补强.pdf` 图 6.1）
   - 结合图 8.2 说明二次型等值椭球扁平度恰为 $\sqrt{\kappa_2(\Sigma)}$；结合图 6.1 展示 12 只真实美股去均值收益率矩阵 $X\in\mathbb{R}^{252\times 12}$ 的奇异值谱：$\kappa_2(X)=6.95$，形成 Gram 协方差阵后精确平方恶化为 $\kappa_2(\Sigma)=48.30$；同时验证 Eckart–Young–Mirsky 定理（前 3 秩即捕获 `70.69%` 总能量、2-范数误差严格等于 $\sigma_4=0.2509$），并衔接 `Lec0` 的 DeepSeek-V3 MLA 与 LoRA 低秩压缩。
3. **2:10–3:00 现场运行 `verify_manuscript_math.py`**（终端执行一行命令）
   - 展示脚本 1 秒内自动通过 9 组定理/反例与 `Lec9` p.31–32 全部 10 道课后题（特别指出习题 8 复矩阵正规性验证与习题 10 矩阵 $B$ 行列式为 0 属奇异半正定而非正定），证明书稿无任何手算错误。

### 老师高频追问与参考回答
- **Q：如何不借助复杂微扰论直接从 2-范数 Eckart–Young 推出 Frobenius 范数最优性？**  
  A：利用奇异值极小化构造：对任意 $\mathrm{rank}(B)\le k$，将 $B$ 加上 $A-B$ 的秩 $(i-1)$ 截断 SVD，其总秩不超过 $k+i-1$，套用已证的 2-范数界立得 $\sigma_i(A-B)\ge\sigma_{k+i}(A)$，两边平方求和即证 Frobenius 范数最优。
